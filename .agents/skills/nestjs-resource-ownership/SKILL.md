---
name: nestjs-resource-ownership
description: 新增或修改 NestJS 资源访问、更新或删除接口时，将 JWT 身份与 Prisma 归属条件绑定，防止越权及拒绝响应泄露资源存在性。
---

触发条件：任务涉及资源归属、受限查询或仅创建者可执行的写操作。

1. 确认资源的访问策略：商品列表/详情允许共享查看，商品修改/删除仅创建者可执行；分类当前共享维护，不无故增加归属限制。
2. 通过 JWT Guard 验证身份，只从验证后的请求上下文获取当前用户 ID；忽略或拒绝客户端提供的归属 ID，创建资源时由服务端赋值。
3. 对需归属限制的查询和写操作同时附带资源 ID 与当前用户 ID 条件；更新/删除必须在实际数据库写条件中保留归属，不能只先查归属再按 ID 写入。必要时使用支持复合条件的操作并检查影响行数。
4. 对有效身份下的“不存在”和“不属于当前用户”统一返回相同状态及通用文案（默认 404），不得额外查询并报告真实拥有者或存在性；未认证返回 401。共享读取接口继续遵循已明确的共享策略。
5. DTO 白名单拒绝归属字段篡改，响应不包含密码哈希等敏感字段。验证本人、他人、不存在资源、伪造归属及无效 JWT；同步调整对应契约测试、Swagger 和 API 文档，不保留泄露存在性的旧断言。
