---
name: frontend-form-feedback
description: 新增或修改 React/Ant Design 表单、提交操作及 API 错误反馈时，对齐后端 DTO，并提供字段级校验和明确的操作状态。
---

触发条件：注册/登录、商品或分类表单及其提交反馈发生变化。

1. 对照后端 DTO/Swagger 核对必填、长度、范围、格式和可选字段。区分创建/编辑，不提交只读或归属字段；金额使用契约要求的字符串，密码不擅自 trim。
2. 使用 Ant Design Form 的字段规则校验，错误紧邻字段展示。提交前校验，提交中显示 loading 并阻止重复提交；失败保留已填内容，成功后再重置或关闭表单并刷新数据。
3. 沿用统一 Axios 封装和拦截器；仅将后端明确可定位且属于当前表单的字段错误映射到 `form.setFields`。无法安全定位的错误显示通用反馈，不猜测字段、不展示原始异常堆栈或私密信息。
4. 为网络失败提供重试入口，为成功/失败提供 message 或 notification；401 按现有约定清理会话并导航登录，403/404 给出通用反馈，不推断资源存在性。避免拦截器与页面重复弹错。
5. 验证非法输入、后端字段错误、网络中断、重复点击、成功后的数据刷新与编辑回显；同步受影响的表单测试及契约文档，如实记录验证范围。
