# 账号删除与恢复

## 已确认规格

- 软删除保留账号及其商品、订单、归属关系，立即撤销会话并禁止登录。恢复保留原角色，停用角色仍不可登录；删除和恢复均递增 tokenVersion。
- 硬删除仅允许系统 ADMIN 且具有 user:purge 权限，目标须已软删除且无任何商品、任何状态订单；不级联删除业务数据。确认用户名及操作原因。
- 禁止删除自己或最后一个有效管理员；账号生命周期操作与角色调整使用同一事务锁。已删除账号不得调整角色。
- user:delete / user:restore / user:purge 初始只授予 ADMIN。委派人员不得删除或恢复超出自身授权范围的角色账号，不能操作系统管理员。
- 用户名、邮箱在软删除期间保留；硬删除后可重新注册，必须产生新 UUID。
- 独立审计保留操作者/目标 UUID、用户名快照、操作、原因、时间，不保存凭据，无用户级联外键。
- 生命周期只允许主库写入；软删除信息以主库为准。永久删除墓碑参与同步，任何延迟 UPSERT 均不得复活原 UUID。
- 列表与统计使用相同状态/角色/搜索条件。回收站展示删除时间与原因，提供恢复、关联检查和彻底删除。

## 实施与验收

1. 先补 HTTP 失败测试，生成 create-only 迁移，审查新增字段、审计、墓碑、权限与同步保护 SQL。业务库部署前需人工审阅。
2. 后端实现严格 DTO、状态查询、关联检查、软删除/恢复/硬删除；认证、个人资料写入排除删除账号；事务锁下复查权限及最后管理员。
3. 同步桥保留主库生命周期信息，忽略墓碑后的用户事件；隔离测试覆盖存量升级、双库生命周期一致、延迟事件不复活。
4. 前端增加回收站及操作确认，覆盖权限隐藏、校验与失败反馈；保留注册规则。
5. 构建、lint、格式、HTTP/双库/浏览器回归；审查后备份业务库、排空同步队列、迁移及更新 Docker，验证后提交推送。

## 验收重点

- 删除后登录及旧 HTTP/Socket 会话不可用；恢复后只接受重新登录产生的新凭证。
- 有商品/订单禁止硬删除；审计在硬删除后仍可查询；历史订单及库存不变。
- 自删、越权、重复操作、最后管理员保护、额外敏感字段、列表统计一致、并发角色操作均受保护。
- 副本不能直改生命周期；延迟资料/密码同步不能撤销软删除或复活已永久删除 UUID。
