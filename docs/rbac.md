# 两角色权限与资源归属

| 能力 | 运营人员 OPERATOR | 管理员 ADMIN |
| --- | --- | --- |
| 商品列表/详情 | 全部 | 全部 |
| 创建商品 | 当前账号为所有者 | 当前账号为所有者 |
| 修改/删除商品 | 自己 | 全部，保留原归属 |
| 分类读取 | 全部共享分类 | 全部共享分类 |
| 分类写入 | 无 | 允许，引用中的分类不可删除 |
| 图片上传 | 允许 | 允许 |
| 个人中心 | 仅自己 | 仅自己 |
| 账号列表/调整角色 | 无 | 允许，禁止自改角色 |

## 注册与登录

注册页选择运营人员或管理员，默认运营人员。运营人员无需额外标识；管理员必须输入公司内部 ID，由后端与私有配置 ADMIN_REGISTRATION_COMPANY_ID 比较，缺失/错误返回 400，配置缺失返回 503，拒绝创建账号。公司内部 ID 不保存在用户表，不返回响应，不写入前端构建或仓库；不影响已有管理员登录。

登录页仅两个身份入口，可选 loginRole 核对数据库角色；入口选择不能更改权限，省略时兼容旧客户端。注册 role 仅决定经过校验的新账号角色，不能修改已有账号。用户名/邮箱唯一冲突返回 409。

## 后端安全边界

权限映射位于 backend/src/auth/permissions.ts。JWT 验证签名、过期、tokenVersion，再从数据库读取当前角色与权限。PermissionsGuard 缺少权限声明默认拒绝。商品共享读取将同一筛选 where 传给列表与总数，Repeatable Read 快照保持一致；修改/删除单独应用 productScope，并保留在实际写条件中。无权限返回 403；越权写入与不存在统一 404。创建者固定来自 JWT，不能从客户端传入归属。

全局 DTO 使用 whitelist、forbidNonWhitelisted、forbidUnknownValues。注册仅允许 username/email/password/role/companyId；个人资料、商品等接口仍拒绝角色和归属字段。companyId 仅用于管理员注册，不作为登录凭证。

管理员角色调整使用事务锁，锁内复查操作者身份；禁止自改角色、重复设置及降级最后管理员。角色、tokenVersion 递增、审计原子提交；失败全部回滚，旧会话返回 SESSION_REVOKED 后重新登录。前端仅做入口和按钮控制，后端独立校验。
