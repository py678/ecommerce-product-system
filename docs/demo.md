# 功能演示脚本

建议演示时间 8–10 分钟。先启动 Compose 并确认 db、backend、frontend 健康，migrate 为 Exited 0；打开 http://localhost:8088。演示时不要展示 .env、令牌或 Docker inspect 的原始输出。

1. **架构与启动**：展示仓库目录、ER 图及 `docker compose ps -a`，说明 React/Nginx → NestJS → Prisma/PostgreSQL，迁移先于业务服务启动。
2. **注册登录**：新注册一个演示账号；展示确认密码验证、退出后重新登录、错误密码反馈。说明数据库存储 BCrypt 哈希，接口使用 JWT。
3. **分类管理**：创建“演示数码”分类并修改名称，展示分页搜索。
4. **商品管理**：创建关联该分类的商品，填写名称、描述、价格 `129.90` 和库存 `7`；展示非法金额校验。按名称搜索、按分类筛选，打开详情。
5. **编辑与刷新**：把价格改为 `99.95`、库存改为 `0`，展示缺货反馈；刷新详情页，确认数据和登录状态保留。
6. **权限与引用保护**：另一浏览器独立注册第二个账号，查看共享商品但不可修改/删除；原账号尝试删除有商品引用的分类，说明保护规则。
7. **删除与反馈**：用创建者账号删除商品，再删除空分类，展示确认提示和成功反馈。
8. **API 与质量**：打开 `/docs`，展示接口、DTO 和响应结构；展示测试命令及最近验证记录，不暴露访问令牌。说明金额使用十进制字符串、归属由服务端校验。
9. **过程与边界**：展示 Conventional Commits 历史、每日推送记录及项目计划；说明当前未实现分类树、刷新令牌和服务端登出撤销，Docker 配置面向本机演示。

演示前关闭敏感文件和终端输出。演示账号可保留用于答辩；仅删除自己创建的演示商品和分类。仓库地址为 https://github.com/py678/git1，向导师发送的状态需要本人确认。
